Mathematical induction.

Tool for proving some claim P(n) holds for all natural numbers n



The induction domino effect:

    ( P(1) ∧ ∀ k (P(k) → P(k+1)) ) → ∀ n P(n)

    P(1) - the claim is true for n = 1

    ∀ k (P(k) → P(k+1)) for all natural numbers in domain, if it's true for P(k),

Revisit our example:

We want to prove that for any positive integer n:

    1 + 2 + ... + n = n*(n+1)/2


claim: P(n)

Proof by induction.

Base case: must prove claim holds for the first pos int n,
n = 1. We have left side of claim, RHS: 1(1+1)/2 = 1
two sides are equal so base case holds

Inductive step: Assume inductive hypothesis: 1 + 2 + ... + k = k(k+1)/2
    for some fixed positive integer k. must show that our claim holds for k + 1

We have that: 1 + 2 + ... + k + (k + 1) = k(k + 1) / 2 + (k + 1) (by inductive hypothesis)
        ...     = (k + 1)((k + 1) + 1)/2
    The claim holds for k + 1. 

We have proved base case and the inductive step, our claim holds by induction for all
    positive integers n.

label base case and inductive step, full sentences. start with "we assume (inductive hypothesis)"

Example: Prove that 3^n - 1 is even for all positive integers n.


what does "even" mean? divisible by 2
{ x : x = 2k, k in Z, k >= 1 }


Proof by induction.
Base case: must prove that our claim holds for the smallest positive integer k = 1
We have that 3^1 - 1 = 2. since 2 = 2 * 1, where 1 is an integer. 2 is even. The base case holds

Inductive step: We assume the inductive hypothesis, that 3^k - 1 is even for
    some fixed positive integer k.
We must prove that 3^(k+1) - 1 is also even.

Since 3^k - 1 is even, 3^k - 1 = 2a where a is an int
    3^(k + 1) - 1 = 3*3^k - 1
                  = 3*(3^k - 1) + 2
                  = 3*2a + 2
                  = 6a + 2
                  = 2(3a + 1)
3^(k+1) - 1 = 2(3a + 1), 3a + 1 is an int, 3^(k+1) - 1 is even.
