Review:

The induction domino effect:

    ( P(1) ∧ ∀ k (P(k) → P(k+1)) ) → ∀ n P(n) 


Steps for an induction proof?
    if we can prove ( P(1) ∧ ∀ k (P(k) → P(k+1)) )  ... 
    we are promised ∀ n P(n) 

P(1) base case - prove our claim for the smallest value in our domain

∀ k (P(k) → P(k+1)): inductive step 
    assume it is true for P(k) for some random k in our domain, 
    prove its still true for P(k+1)

Example: Prove that the sum of the first n odd numbers is n^2.

    (what is our domain?)
    domain is natural numbers 

base case would be the sume of the first 1 odd number 

How can we express the sum of the first n odd numbers more formally?

1 + 3 + 5 + ... + nth odd = n^2

So, what is our claim? for all natural numbers n, we want to prove:
    1 + 3 + 5 + ... + (2n - 1) = n^2


Proof by induction.
Base case: we must prove our claim for the smallest natural number, n = 1
    1 = 1^2, the base case holds

inductive step: We assume the inductive hypothesis, that:
    1 + 3 + 5 + ... + (2k - 1) = k^2
k is a fixed natural number. we must show that 1 + 3 + 5 + ... + (2k - 1) + (2(k+1)-1) = (k+1)^2

we have: 
1 + 3 + 5 + ... + (2k - 1) + (2(k + 1) - 1) = k^2 + (2(k + 1) - 1) (by inductive hypothesis)
                            = k^2 + 2k + 1
                            = (k + 1)^2
inductive step holds

We have shown with induction that for all natural numbers n, 1 + 3 + 5 + ... + (2n - 1) = n^2

Bad induction, example 1.

Use induction to prove that in any nonempty set of n horses, 
all horses are the same color.

domain: natural numbers
Base Case: we must prove that our claim holds for the smallest
natural number, n = 1. We have a set of 1 horse, all horses would be the same color.

inductive step: We assume the inductive hypothesis that any set of k horses, 
where k is a natural number, that all k horses have the same color.
We must show that if we have a set of k + 1 horses, all horses have the same color.

never getting away from the classes that make my life confusing


To define a function whose domain is the set of natural numbers
(or some other set of integers with a lowest value)

Base case: Specify the value of the function at 1 (or some other
    lowest value). (There may be more than one base case.)


Recursive step: Give a rule for finding the value of the function
    at all bigger integers in our domain using its smaller values
